Ders içeriği

Katalogdaki adı: Bilgisayar Destekli Peyzaj Mimarlığı.

İngilizce adı: Computer Aided Landscape Architecture.

Öğrenme çıktıları

  • Bilgisayar ortamında tasarım ve uygulama yapabilme
  • Peyzaj tasarımında kullanılan bilgisayar destekli tasarım metotlarını kullanabilme
  • Peyzaj Tasarımında Autocad programını kullanabilme
  • Peyzaj tasarımında 3DSMax programını kullanabilme
  • Modelleme mantığı, sahne hazırlama, malzeme oluşturma, rendering ve animasyon konularına yönelik uygulama becerilerini kazanır.
  • Peyzaj tasarım yazılımlarını kullanabilme becerilerini kazanır
