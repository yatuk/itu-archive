Ders içeriği

Katalogdaki adı: Veritabanı Yönetim Sistemleri.

Veri tabanı kavramları. Bağıntı modeli, bağıntı cebri, sorgulama. Uygulama geliştirme. Veri tabanı tasarımı, normalizasyon, varlık - ilişki modeli. Eşzamanlı çalışma, hareketler, kilitler. NoSQL veri tabanları, nesne - bağıntı eşleştirmesi. Database concepts. Relational model, relational algebra, queries. Application development. Database design, normalization, entity - relationship model. Concurrency, transactions, locking. Object - oriented databases, object/relational mapping, XML data model and queries.

Öğrenme çıktıları

  • Büyük miktarda veriyi bilgisayarda etkin işlenebilecek şekilde modelleyebilir.
  • Büyük miktarda veri işleyen yazılımlar gerçekleyebilir.
  • Bir proje için uygun olacak veri modelini ve gerekli veritabanı/yazılım bileşenlerini seçebilir.
  • Takım halinde proje hazırlayıp topluluk karşısında sunma becerisi kazanır.
