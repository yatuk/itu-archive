Ders içeriği

İngilizce adı: Internet Programming.

- Internet Uygulamaları Mimarisi & HTML5 & CSS & JavaScript & Dinamik Web Sayfaları & Dokuman Nesne Modeli & XML & Ajax - Internet Applications Architecture& HTML5 & CSS & JavaScript & Dynamic Web Pages & Document Object Model & XML & Ajax

Öğrenme çıktıları

  • HTML, CSS, JavaScript gibi temel web tasarımı ögelerini kullanarak web sayfası hazırlayabilme.
  • Web sunucularının çalışma ilkelerini ifade edebilme.
  • Dinamik web siteleri geliştirebilme.
Haftalık konular (14 hafta)
  1. 1. haftaBilgisayar ve İnternete Giriş ve Temel kavramlar
  2. 2. haftaInternet Uygulamaları Mimarisi
  3. 3. haftaHTML5'e Giriş ve Temel Kavramlar
  4. 4. haftaCSS - Basamaklı Stil Sayfalarına Giriş ve Temel Kavramlar
  5. 5. haftaJavaScript: Betik Programlamaya Giriş
  6. 6. haftaJavaScript: Kontrol İfadeleri (if-else, while, atama komutları)
  7. 7. haftaYapay Zeka Destekli Kod Geliştirme — AI kodlama asistanları (GitHub Copilot, Claude Code vb.), prompt mühendisliği ile web geliştirme, kod tamamlama ve hata ayıklamada AI kullanımı
  8. 8. haftaArasınav, JavaScript: Fonksiyonlar (parametreli / parametresi, değer döndüren / değer döndürmeyen)
  9. 9. haftaJavaScript: Diziler (Tek boyutlu / İki boyutlu) ve Nesneler (Math, String, Date, Document)
  10. 10. haftaJavaScript: Nesneler
  11. 11. haftaJavaScript: Olaylar
  12. 12. haftaDoküman Nesne Modeli
  13. 13. haftaBootstrap: Giriş ve Temel Kavramlar
  14. 14. haftaYapay Zeka API Entegrasyonu ile Web Uygulamaları — OpenAI/Claude API'lerine giriş, fetch/Ajax ile AI servislerine bağlanma, basit bir chatbot arayüzü geliştirme

Kaynaklar

  • Ruse Ferguson, Christian Heilmann, Beginning JavaScript with DOM Scripting and Ajax, Apress (2013)
  • Jon Duckett, HTML & CSS design and build websites, Wiley (2011)
