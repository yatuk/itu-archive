Ders içeriği

Katalogdaki adı: Endüstriyel Kumanda Sistemleri.

Fundamentals of industrial electrical control systems. Control circuit devices: Contactor, auxiliary relay, timing relay and protection relays. The common standards for electrical control systems. Relay control (contact/coil) logic. Time-driven and event-driven sequential processes. Relation of digital processor based control systems to relay control circuits. Programmable logic controllers (PLCs): Internal structure of a PLC: Central processing unit, input-output interface, memory structure. PLC operating system and program processing. Programming language: instruction set, ladder diagram and function chart. The common instruction set, timer, counter, arithmetic and comparison functions. Selection criteria for PLC. Implementation of relay and PLC based industrial automated systems. Industrial applications.

  • Endüstriyel kumanda kavramlarını anlamak ve onları endüstriyel üretimde karşılaşılan sorunların çözümünde kullanmak
  • Donanım öğelerinin seçimi konusundaki bilgisini geliştirmek
  • Otomasyon sistemlerini çözümleme, tasarım ve gerçekleme için bilgisayar ve yazılımlarını kullanmak
  • Etkin iletişim ve Türkçe rapor sunmak
