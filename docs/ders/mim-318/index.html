Ders içeriği

İngilizce adı: Computer Appl. in Evaluation of Climatic Perf. of Built Env.

İlk olarak, yapma çevrede iklimsel performans değerlendirme problemi açıklanmaktadır. Ayrıca, yapma çevrede performans değerlendirmede kullanılan bilgisayar programları tanıtılmaktadır. Bilgisayar yardımı ile yapma çevrede iklimsel performans değerlendirilmesi yapılmaktadır. Sonuç olarak, bilgisayar programlarının karşılaştırılması yapılmaktadır. Firstly, the problem for climatic performance evaluation in built environment is explained. Furthermore building energy performance evaluation tools are defined. Climatic performance evaluation in built environment by means of computer programs are done. As a result, computer programs are compared.

Öğrenme çıktıları

  • Yapma çevrenin iklimsel açıdan performansının değerlendirmesinden haberdar olma
  • Yapma çevrede performans değerlendirmede kullanılan bilgisayar programlarını araştırma ve öğrenme
  • Bilgisayar programları yardımı ile yapma çevrenin iklimsel performansını değerlendirmeyi öğrenme
  • Performans değerlendirme sonuçlarını anlama
