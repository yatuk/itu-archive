Ders içeriği

Katalogdaki adı: Yapı Sistemlerinde Enerji Metodları.

İngilizce adı: Energy Methods in Structural System.

Giriş, işin tanımı ve hesabı. Şekil değiştirme enerjisi. Virtüel iş ilkesi. Toplam potansiyel enerji ilkesi. Toplam potansiyel enerji ilkesi kullanılarak eksenel eleman problemlerinin çözümü, kafes sistemler, kafes sistemlerin çözümünde bilgisayar programlama alt yapısının oluşturulması, özel durumlar(eğik mesnet, elastik mesnet, sıcaklık etkisi, montaj hatası). Eşdeğer potansiyel enerji ile eğilme elemanı, hiperstatik problemler. Çerçeve sistemlerin çözümü, çerçeve sistemler için bilgisayar programlama alt yapısının oluşturulması. Sonlu elemanla yapı sistemlerinin çözümüne giriş. Introduction, definition of work. Strain energy. Virtual work principle. Principle of total potential energy. The solution of axial elements by using total potential energy. Truss systems, introduction to computer programming of truss system. Special cases such as inclined support, elastic support, temperature effect, assembly error. The solution of bending elements by using equivalent potential energy, hyperstatical problems. The solution of frame elements by using equivalent potential energy, introduction to computer programming of frames. Introduction to finite element for structures.

Öğrenme çıktıları

  • İşin tanımı, virtüel iş ilkesi
  • Toplam ve eşdeğer potansiyel enerji
  • Matris işlemleri, rijitlik, elemanların birleştirilmesi, dönüşüm matrisi
  • Eksenel, eğilme, çerçeve elemanlarının static analizi
  • Kafes, çerçeve elemanlar için uygulamalar
  • Dinamik analiz
