Ders içeriği

Katalogdaki adı: Fiyatlandırmave Gelir Yönetimi.

Fiyat optimizasyonu, Fiyat farklılaşması, Gelir yönetimi, Kapasite dağılımı, Fazla rezervasyon, İndirim yönetimi, Özel fiyatlandırma. Price optimization, Price differentiation, Revenue management, Capacity allocation, Overbooking, Markdown management, Specialized pricing.

Öğrenme çıktıları

  • Fiyat optimizasyonu, fiyat farklılaşması ve dinamik fiyatlama kavramlarını öğrenir
  • Miktara yönelik gelir yönetimi modellerini uygular
  • Fiyata yönelik gelir yönetimi modellerini uygular
  • Temel yöneylem araştırması yöntemlerini gelir yönetimine uygular
  • Farklı sektörlerde gelir yönetimi modellerini uygular
