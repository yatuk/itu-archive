Ders içeriği

Katalogdaki adı: Veri Bilimi için Programlamaya Giriş (Python).

Problem modelleme, algoritmalar. Seçme ve yineleme yapıları. Bileşke veri yapıları. Soyutlama. Temel giriş-çıkış işlemleri. Web uygulamaları. Problem modelling, algorithms. Selection and repetition constructs. Composite data types. Abstraction. Basic input/output operations. Web applications.

Öğrenme çıktıları

  • Bir algoritma geliştirerek bilgisayar programı yardımıyla bir problemi çözmek için modellemek.
  • Küçük ve orta ölçekli bilgisayar programlarını tasarlayabilmek, gerçekleyebilmek ve sınayabilmek.
  • Python programlama dili için geliştirme araçlarıyla tanışıklık edinmek.
  • Temel programlama tekniklerine hakim olmak.
  • Temel web istemci ve sunucu teknikleriyle tanışıklık edinmek.
Haftalık konular (14 hafta)
  1. 1. haftaGiriş. Program geliştirme aşamaları. Algoritmalar.
  2. 2. haftaVeri tipleri. İfadeler. Değişkenler.
  3. 3. haftaKarar yapıları.
  4. 4. haftaYineleme yapıları.
  5. 5. haftaBileşke veri tipleri.
  6. 6. haftaFonksiyonlar (I).
  7. 7. haftaFonksiyonlar (II).
  8. 8. haftaFonksiyonlar (III).
  9. 9. haftaSınıflar.

  11. 11. haftaHata denetimi.
  12. 12. haftaKatar ve dosya işlemleri.
  13. 13. haftaWeb istemcileri.
  14. 14. haftaWeb uygulamaları.

Kaynaklar
