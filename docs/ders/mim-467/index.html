Ders içeriği

İngilizce adı: Pascal Programming.

Bilgisayar programlamaya ilişkin temel bilgiler: • Algoritma kurma ve geliştirme o Değişken ve veri tipleri, o İşlemciler, ifadeler, o Giriş-Çıkış Deyimleri, o Kontrol Deyimleri, o Döngü yapıları ve deyimleri, o Prosedür ve fonksiyon yapısı • Programların genel yapısı ve program oluşturma süreci o Akış diyagramı yapıları Mimarlık problemlerine dönük programlama uygulamaları. • Mimari formun bilgisayara tanımında kullanılan modeler • Tanım teknikleri ve uygulamaları Fundamentals of computer programming; • Algorithm development o Variables and data types, o Operators, expressions o Input – Output statements, o Conditional statements, o Loop structures and statements o Procedure and function structure • General structure of programming and programming process o Flowchart structures Programming applications for architectural problems. • Models used for the definition of architectural form to computer • Definition techniques and applications

Öğrenme çıktıları

  • Bir problemi bilgisayar ortamında çözme becerileri
  • Bilgisayar programlama becerileri
  • Mimari formu bilgisayar ortamında temsil etme becerileri
  • Mimarlık problemlerini bilgisayar ortamında çözme becerileri
