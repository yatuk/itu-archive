Ders içeriği

Bu ders veri bilimindeki temel kavramları, teknikleri ve uygulamaları tanıtmaktadır. İstatistikten, makine öğrenmesine, grafik analizi ve paralel programlama tekniklerine, tavsiye sistemi ve duygu analizi gibi uygulamalara yönelik verilerin analizine odaklanır. Yeni kavramlar, gerçek verileri kullanarak vaka çalışmaları ile gösterilmektedir. Soruların çözümleri için Python programlama dili kullanılmaktadır This course introduces to main concepts, techniques, and applications in data science. It focuses on the analysis of data, covering concepts from statistics to machine learning, techniques for graph analysis and parallel programming, and applications such as recommender systems or sentiment analysis. New concepts are are illustrated by practical cases using real data. The solutions to the questions are implemented using Python programming language.

Öğrenme çıktıları

  • Veri bilimindeki temel kavram ve yöntemleri anlama becerisi
  • Veri bilimindeki temel yöntem ve teknikleri uygulama becerisi
  • Python programlama dili ile uygulama becerisi
  • İş dünyasındaki gerçek problemlere veri bilimi ile çözüm geliştirebilme becerisi
