Ders içeriği

İngilizce adı: Brushless Electric Motors.

Fırçasız makine teknolojisine giriş. Fırçalı motorların çalışma ilkesi, fırçasız çalışma, fırçasız motor türleri ve yapıları, sürücü devreler, rotor konumu algılayıcılar, kod çözücü devreler, fırçasız motorların kontrolü, sürekli mıknatıs malzemeler, algılayıcısız kontrol teknikleri, tasarım sorunları. This is an introductory course in the field of brushless machine technology. Including brushed type machine operation, brushless operation, types and structures of brushless motors, driver circuits, rotor position sensors, decoder circuits, control of brushless machines, permanent magnet materials, sensorless control techniques, design issues.

Öğrenme çıktıları

  • Fırçasız elektrik makinelerinin çalışma ilkelerini öğrenme.
  • Fırçasız makine tasarımının temellerine sahip olma
  • Fırçasız motorları modelleyebilmek için çeşitli yazılımları kullanabilme
  • Fırçasız elektrik motor sürüş sistemlerini kontrol etmek için çeşitli yöntemler kullanabilme
  • Fırçasız motor sürüş sistemlerinde uygulamalı deneyler gerçekleştirebilme
  • Fırçasız elektrik motorlarının endüstri uygulamaları hakkında kapsamlı bilgiye sahip olma
