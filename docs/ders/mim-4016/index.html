Ders içeriği

İngilizce adı: Computer Appl. in Evaluation of Climatic Perf. of Built Env.

Yapma çevrede iklimsel performans değerlendirme probleminin tanıtımı: Yapma çevrede performans değerlendirmede kullanılan bilgisayar programları: Bilgisayarla iklimsel performans değerlendirme örnekleri. Definitions of the problem for climatic performance evaluation in built environment. Computer programs for evaluation of climatic performance of built environment. Examples for computer aided evaluation of climatic performance
