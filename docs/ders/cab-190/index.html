Ders içeriği

İngilizce adı: Instrumentation II.

Yaylı çalgılar: keman, viyola, viyolonsel, kontrbas, yaylı çalgı bileşimleri, tahta üflemeli çalgılar: flüt, obua, korno, klarnet, fagot, tahta üflemeli çalgı bileşimleri, Yaylı çalgılar ve tahta üflemeli çalgılar bileşimleri. The technical features of strings instruments, the technical features woodwind instruments, combination of strings and woodwinds

Öğrenme çıktıları

  • Yaylı çalgıları tanıma.
  • Yaylı çalgılarda bileşimler hakkında bilgi sahibi olma.
  • Tahta üflemeli çalgıları tanıma.
  • Tahta üflemeli çalgılarda bileşimler hakkında bilgi sahibi olma.
  • Yaylı ve tahta üflemeli çalgı bileşimleri hakkında bilgi sahibi olma.
