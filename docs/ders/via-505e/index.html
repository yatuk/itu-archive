Ders içeriği

Gelişen teknolojiler ile birlikte günümüzde artık çok farklı kaynaklarda oluşan veriler saklanabilmekte ve işlenebilmektedir. Analitik uygulamalar ise günümüzde veri kaynaklarını etkin kullanabildiği ölçüde değer oluşturabilmektedir. İşletmelerde geleneksel yazılımlar ile oluşan işlem verileri ilişkisel veri tabanlarında tutulurken, büyük veri olarak tanımlayabileceğimiz veriler için yeni veri tabanı modelleri oluşturulmaktadır. Bu ders kapsamında geleneksel ve yeni veri tabanı modelleri anlatılmaktadır. Today, with the help of emerging technologies, the data formed in various sources can be stored and processed easily. Analytical applications create value as the data sources can be used effectively. In the enterprises, while the transaction data generated are stored in relational databases, new database models are created for the big data. In this course, traditional and new data base models are explained.
