Ders içeriği

Katalogdaki adı: Veri Bilimi için Programlamaya Giriş.

Problem modelleme, algoritmalar. Seçme ve yineleme yapıları. Bileşke veri yapıları. Soyutlama. Temel giriş-çıkış işlemleri. Bellek yönetimi. Uygulama Geliştirme. Problem modelling, algorithms. Selection and repetition constructs. Composite data types. Abstraction. Basic input/output operations. Memory Management. Application Development.

Öğrenme çıktıları

  • Bir algoritma geliştirerek bilgisayar programı yardımıyla bir problemi çözmek için modellemek.
  • Küçük ve orta ölçekli bilgisayar programlarını tasarlayabilmek, gerçekleyebilmek ve sınayabilmek.
  • Programlama dili için geliştirme araçlarıyla tanışıklık edinmek.
  • Temel programlama tekniklerine hakim olmak.

  3. 3. haftaKarar yapıları.
  4. 4. haftaYineleme yapıları.
  5. 5. haftaBileşke veri tipleri.
  6. 6. haftaFonksiyonlar (I).

  14. 14. haftaUygulama Geliştirme
