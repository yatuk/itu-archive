Öğrenme çıktıları

  • Temel AutoCAD bilgisine sahip olabilir.
  • Basit objeleri çizebilir.
  • Objelerin düzenlenmesini yapabilir.
  • OSNAP komutlarını kullanabilir.
  • Teknik resimleri ölçülendirebilir.
  • Parçaların görünüşlerini çizebilir.
  • Parçaların kesit görünüşlerini çizebilir.
  • Parçaların izometrik görünüşlerini çizebilir.
  • Parçaların 3 boyutlu görünüşlerini çizebilir.
