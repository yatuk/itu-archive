Ders içeriği

1. kademe / register, Horlatma tekniğine giriş. Horlatma tekniğinin geliştirilmesine yönelik uzun ses çalışmaları.1. perde düzeninde 1 oktav içerisinde horlatma tekniğine yönelik egzersizler. Farklı horlatma tonları elde etmeye yönelik dudak hâkimiyetini geliştirme çalışmaları. Horlatma tekniğinin Türk Halk Müziği repertuarından seçilen eserler üzerinde 1. ve 2. perde düzenlerinde uygulanması. 1st register, introduction to horlatma techniques. Long note exercises in order to improve horlatma technique. On the 1st fret exercises covering one octave in order to improve horlatma techniques. Studies to improve lip control in order to have different tones. Practising horlatma techniques on pieces from Türk Halk Müziği repertoire on 1st and 2nd fret.

Öğrenme çıktıları

  • Dilsiz Kaval’da horlatma tekniğini kullanabilme.
  • Dilsiz Kaval’da 1. ve 2. perde düzenlerinde farklı horlatma tonlarını kullanabilme.
  • 1, 2, 3 ve 4. kademeler arasında geçişler yaparak ses sahasını en etkin biçimde kullanabilme.
  • İcra edeceği eserlerde farklı horlatma tonlarını kullanarak etkili sunum yapabilme.
