Ders içeriği

Katalogdaki adı: Python ile Sayısal Analiz.

Temel seviye Python programlama. Sayısal Yöntemlerin tanımı ve özellikle mühendislik uygulamalarındaki kullanımının açıklanması. Lineer ve lineer olmayan denklem sistemi çözümleri, yaklaşım yöntemleri, interpolasyon, lineer regresyon, kök bulma, sayısal türev ve integrasyon, başlangıç değer problemleri. Sayısal yöntemlerin Python programlama teknikleriyle uygulanması. Introductory level Python programming. Description of Numerical Methods and application of them particularly in engineering. Numerical methods for the solution of systems (lineer and nonlinear), approximation methods, interpolation, linear regression, root finding, numerical differentiation and integration, initial value problems. Application of numerical methods using Python programming techniques.

Öğrenme çıktıları

  • Bilimsel ve mühendislik hesaplamalarında Python programlama dilini nasıl kullanacaklarını öğrenecek
  • Sayısal yöntemlerin temellerini anlayacak
  • Mühendislikte bir problemin analizinde sayısal yöntemleri kullanma becerisine sahip olacak
Haftalık konular (14 hafta)
  1. 1. haftaCore Python: Python yorumlayıcısı, veri yapıları, operatörler, karar koşul yapıları ve döngüler
  2. 2. haftaPython Fonksiyon ve Mödülleri: değişken kapsamı, fonksiyonlar, moduller, dosyadan okuma yazma
  3. 3. haftaPython Matematik Modülleri: matematik fonksiyonları, numpy, scipy, matplotlib
  4. 4. haftaLinear Denklem Sistemleri: Çözülebilirlik, Gauss Eliminasyonu
  5. 5. haftaİteratif Metodlar- Jacobi Method, Gauss-Seidel
  6. 6. haftaİnterpolasyon ve Yaklaştırma: Newton bölünmüş farklar yöntemi, Lagrange metodu
  7. 7. haftaİnterpolasyon and Regresyon: şerit fonksiyonları kullanarak interpolasyon, En küçük kareler yaklaşımı
  8. 8. haftaKök Bulma: İkiye bölme Metodu, Newton-Raphson Metodu
  9. 9. haftaKök Bulma: Secant Metodu, Sabit Nokta İterasyonu, kararlılık
  10. 10. haftaSayısal Türev: Sonlu fark yaklaşımı, Richardson Extrapolasyonu
  11. 11. haftaSayısal İntegrasyon: Trapez ve Simpson Kuralları
  12. 12. haftaSayısal İntegrasyon: Romberg Sayısal İntegrasyonu
  13. 13. haftaBaşlangıç Değer Problemleri: Euler Metodu
  14. 14. haftaBaşlangıç Değer Problemleri: Runge-Kutta Metodları

Kaynaklar

  • Numerical Methods in Engineering with Python 3, Jaan Kiusalaas
