Ders içeriği

Katalogdaki adı: Kontrol ve Görselleştirme için Entegre Yazılım Çözümleri.

Yazılım ve görselleştirme araçlarına giriş, kontrol uygulamaları için yazılım mimarileri, GUI programlama kavramları ve form tabanlı arayüzler, olay işleme ve gerçek zamanlı kullanıcı etkileşimi, nesne yönelimli programlama kavramları, mühendislik uygulamalarında sorgu benzeri veri erişimi, veri yönetimi, loglama ve görsel geri bildirim, dinamik sistem modelleme ve simülasyonunun temelleri, dinamik sistemler için gerçek zamanlı veri görselleştirme, kontrol yazılımlarında sonlu durum makinelerinin uygulanması, dijital kontrolörlerin (PID vb.) yazılımla uygulanması, donanım bileşenleriyle arayüz oluşturma (mikrodenetleyiciler vb.), yazılım geliştirmede hata yönetimi ve test yaklaşımları. Introduction to software and visualization tools, software architectures for control applications, GUI programming concepts and form-based interfaces, event handling and real-time user interaction, object-oriented programming concepts, query-like data access in engineering applications, data management, logging and visual feedback, basics of dynamic system modelling and simulation, real-time data visualization for dynamic systems, application of finite state machines in control software, implementing digital controllers (PID, etc.) in software, interfacing with hardware components (microcontrollers, etc.) exception handling and testing approaches in software development.

Öğrenme çıktıları

  • Kontrolde yazılım ve görselleştirme araçlarının önemini anlar.
  • Dinamik sistemlerin izlenmesi ve kontrolü için kullanıcı arayüzleri geliştirebilir.
  • Kontrol sistem bileşenlerini modellemek için nesne yönelimli programlama çözümleri üretebilir.
  • Yapılandırılmış veri sorgulama yöntemlerini kullanarak veri yönetimi gerçekleştirebilir.
  • Dinamik sistemlerin davranışını simüle edip, gerçek zamanlı görselleştirebilir.
  • Sonlu durum makinalarını ve ilgili diğer araçları kontrol yazılımlarında uygulayabilir.
  • Kontrolörleri (PID gibi) yazılım ile uygulayıp test verileriyle doğrulayabilir.
  • PC ile donanım bileşenleri (mikrokontrolör gibi) haberleşme kurarak gerçek sistemler ile etkileşime girebilir.
  • Yazılımda testlerin nasıl yapılacağını ve test yaklaşımlarını öğrenir.
