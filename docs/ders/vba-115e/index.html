Ders içeriği

Katalogdaki adı: Linux Temelleri.

Bu dersi alan öğrencinin Linux işletim sistemi kavramlarını öğrenmesi, aktif olarak kullanması ve işletim sistemine özgü yazılım geliştirebilmesi amaçlanmıştır. Bu kapsamda temel linux işlemleri, ağ ve sunucu yapılandırılması, sistem yönetimi, izleme ve yorumlama becerisinin arttırılması amaçlanmıştır. The aim of this course is for students to learn the concepts of the Linux operating system, use it actively, and develop software specific to the operating system. In this context, the course aims to teach basic Linux operations, network and server configuration, system management, and to enhance monitoring and interpretation skills.

Öğrenme çıktıları

  • Linux işletim sistemi yapısını bilir.
  • Temel Linux komutlarını, dosya yapısını bilir, sistemi izler, yönetir.
  • Sunucu yönetimi, güvenlik duvarı ve ağ yapılandırmasını yapar, temel ağ işlemlerini kullanır, sistem günlüklerini yorumlar.
  • Linux kabuk betik dili (bash vb.) kullanır.
  • Python, Vala, c#, Java dillerinden biri ile uygulama geliştirir, dağıtım için paket oluşturur.
Haftalık konular (14 hafta)
  1. 1. haftaLinux tarihçesi ve temel kavramlar, komut satırı temelleri, temel komutlar, Dizin I işlemleri, metin düzenleyicileri, uygulamalar
  2. 2. haftaLinux dosya sistemi, disk ve dosya işlemleri
  3. 3. haftaYazılım yönetimi, paket yöneticileri kavram ve uygulamaları
  4. 4. haftaFarklı Linux işletim sistemi dağıtımların incelenmesi, farklılık
  5. 5. haftaSistem yönetimi ve süreçlerin(processes) izlenmesi, yapılandırması
  6. 6. haftaAğ temelleri ve yönetimi, IP adresleri, alt ağlar, yapılandırma, temel ağ komutları
  7. 7. haftaTemel güvenlik kavramları, güvenlik duvarı kullanımı, yapılandırılması
  8. 8. haftaSistem günlükleri, yorumlanması, hata giderme işlemleri
  9. 9. haftaLinux sunucu yönetimi, yapılandırılması, izlenmesi
  10. 10. haftaUygulama geliştirme, Kabuk betik (script) dilleri
  11. 11. haftaUygulama geliştirme, VALA
  12. 12. haftaUygulama geliştirme, c#, Java
  13. 13. haftaUygulama geliştirme, Python
  14. 14. haftaYazılım paketi oluşturulması
