Ders içeriği

Katalogdaki adı: Programlama Mantığına Giriş.

Bilgisayar programlamaya ilişkin temel bilgiler; Algoritma kurma ve geliştirme; Akış diyagramı yapıları; Programların genel yapısı ve program oluşturma süreci; Editör kullanma ve dosyalama; Değişken ve veri tipleri, İşlemciler, ifadeler; Giriş-Çıkış Deyimleri, Kontrol Deyimleri, Döngü yapıları ve deyimleri; Prosedür ve fonksiyon yapısı; Mimari formun bilgisayara tanımında kullanılan modeller, tanım teknikleri ve uygulamaları; Mimarlık problemlerine dönük programlama uygulamaları Fundamentals of computer programming; Algorithm development; Flowchart structures; General structure of programming and programming process; Using editors and file types; Variables and data types; Operators, expressions; Input – Output statements; Conditional statements; Loop structures and statements; Procedure and function structure; Models used for the definition of architectural form to computer; Definition techniques and applications; Programming applications for architectural problems

Öğrenme çıktıları

  • Bir programlama dili kullanarak sayısal ortamda problem çözme becerilerini
  • Mimari formu sayısal ortamda tanımlama becerilerini
  • Tasarım problemlerinin çözümünde sayısal model kullanma becerilerini geliştirmeleri beklenmektedir
