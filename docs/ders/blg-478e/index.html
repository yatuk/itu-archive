Ders içeriği

Katalogdaki adı: Ağ Güvenliği.

Dersin amacı, öğrencilerin bilgisayar güvenliği, özellikle ağ güvenliği kavramlarına aşina olmasını sağlamaktır. Müfredat bu konuları içerir: temel güvenlik kavramlarını, kriptografik yöntemler, erişim kontrolü, işletim sistemleri güvenliği, ağ güvenliği ve protokolleri, güvenli programlama, kötü niyetliler mantığı, güvenlik. The aim of the course is make the students be familiar with the computer security concepts, especially network security. Curriculum contains these subjects: basic security concepts, cryptographic methods, access control, operating systems security, network security and protocols, secure programming, malicious logic, safety.

Öğrenme çıktıları

  • Güvenlik mimarileri bile şenlerini oluşturabilmek ve ayrıştırabilmek
  • Güvenlik protokollerini tasarlayabilmek ve analiz edebilmek
  • Güvenli programlama görevlerini gerçekleştirebilmek
  • İlgili sosyal ve hukuki konular hakkında bilgi sahibi olmak
Haftalık konular (14 hafta)
  1. 1. haftaTemel güvenlik kavramlarına giriş, Kriptografiye giriş
  2. 2. haftaHashing (bozma), bozulmuş mesaj doğrulama kodu, Simetrik algoritmalar
  3. 3. haftaAnahtar dağıtımı ve anahtar değişimi, Asimetrik algoritmalar
  4. 4. haftaSertifikalar
  5. 5. haftaİmza şemaları
  6. 6. haftaDoğrulama Protokolleri
  7. 7. haftaSınıf Çalışması
  8. 8. haftaHaberleşme Güvenliği
  9. 9. haftaAğ Koruması
  10. 10. haftaEmail Güvenliği
  11. 11. haftaWeb Güvenliği
  12. 12. haftaSınıf Çalışması
  13. 13. haftaYönetmelikler, yasalar ve gizlilik
  14. 14. haftaGüvenli Programlama
