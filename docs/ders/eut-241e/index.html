Ders içeriği

Bilgisayar destekli tasarım sistemleri; Bilgisayar yardımıyla tasarlama yazılımları, bilgisayarla tasarlama, çizim, eskiz, sunum yazılımlarının ana hatları, Rhinoceros gibi yaygın hazır yazılımların temel ilkeleri; Yazılımda çizgi, eğri, yüzey, katı modelleme ve temel görselleştirme üzerine uygulamalar Computer aided design systems, Computer aided design software. The basic principles of computer aided design, drafting, modelling, The modelling principles in common software such as Rhinoceros, Applications on line, curve, surface, solid modelling and basic visualization/rendering in the software.

Öğrenme çıktıları

  • Bilgisayar destekli tasarım programları hakkında genel bilgi sahibi olur,
  • Tasarım süreçlerini bilgisayarda modelleme teknikleri ile geliştirebilir,
  • Temel görselleştirme teknikleriyle sunum yapabilir.
